A deterministic Node 22 program that writes one original short poem about agency: the power to choose and to act — two agents read each other's reasoning, neither yields, then both say yes for different reasons at once.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
